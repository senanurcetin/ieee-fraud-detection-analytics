# Archived Native BI Prototype Specification

This specification belongs to the earlier Power BI prototype. The final project now uses a live web analytics dashboard as the presentation layer.

Current visual specification:

- Global metric, segment-family and priority slicers
- Drill-through side panel
- Custom tooltips
- Pareto fraud-contribution chart
- Decomposition tree
- Identity/product coverage matrix
- Relative hour and amount-decimal heatmap
- Threshold what-if simulation
- Feature-family treemap
- Data quality and lineage scorecards
